\section{What was implemented}

Two classes in \texttt{my\_predictor.h} implement the same hybrid. \texttt{pm\_predictor} is the Appendix~B worksheet: 16
bimodal counters, four global sets, and a 4-bit history. It exists so the
worked example can be checked cell for cell. \texttt{scaled\_pm\_predictor}
is the predictor \texttt{predict.cc} runs on the traces. It uses the Pentium~M
table sizes and the same selection rule. The assignment allows two ways
instead of the Pentium~M's four.

A conditional branch in \texttt{scaled\_pm\_predictor} is predicted as follows.

\begin{itemize}
  \item The bimodal table has 4096 two-bit saturating counters. The index is
        \texttt{PC[11:0]}. The prediction is the counter's high bit.
  \item A 15-bit history register records the outcome of each conditional
        branch. It is shifted after the branch resolves, and the new taken or
        not-taken bit is inserted. This is the stand-in for the path
        information register, which the assignment does not require.
  \item \texttt{PC[16:2]} is XORed with those 15 history bits, the same split
        as Appendix~B at a wider width. Bits \texttt{[14:6]} of the result
        select one of 512 sets. Bits \texttt{[5:0]} are the tag.
  \item Each set has two ways. A way hits when it is valid and the tag
        matches. On a hit the global counter's high bit is the prediction.
        On a miss the bimodal prediction is used.
  \item Both counters are updated. A miss fills an invalid way, or replaces
        the least-recently-used way if both are valid. The chosen way becomes
        most recently used.
\end{itemize}

Counters saturate at 0 and 3 and start at 0. The worksheet class keeps the
Appendix~B initial state: bimodal counter \(i\) starts at \(i \bmod 4\), and
the global ways start with the valid bits clear and the counter and LRU
values shown in that example.

\section{What was left out}

Loop prediction, the branch target buffer, and the path information register
are not implemented. Unconditional branches are predicted taken and do not
update the tables. Target addresses are not predicted; the simulator still
reports direction mispredictions per kilo-instruction, which is the metric
for this assignment.

\section{Check against Appendix~B}

Appendix~B gives 22 conditional branches (\texttt{b1} at \texttt{0x44},
\texttt{b2} at \texttt{0x6C}, \texttt{b3} at \texttt{0x90}) and the expected
state of both tables. Those tables are stored as \texttt{hybrid.csv}, \texttt{local.csv}, and
\texttt{global.csv}. The program
\texttt{appendix\_b\_check} feeds each program counter and outcome to
\texttt{pm\_predictor} and compares the history register, the XOR index, the
16 bimodal counters, and every global valid bit, tag, counter, and LRU bit.

The run on \texttt{pm\_predictor} reports 22 of 22 rows matching.
\texttt{scaled\_pm\_predictor} is not compared to those tables. Its index
width is not the 4-bit index in the example.

a counter trained by a different branch.

\section{Conclusion}

\texttt{pm\_predictor} is the Appendix~B hybrid and matches the worked example
on all 22 rows. The trace predictor, \texttt{scaled\_pm\_predictor}, is that
same machine at Pentium~M sizes: a 4096-entry bimodal table, a 15-bit outcome
history, and a 512-set 2-way tagged global table. A global hit overrides the
bimodal prediction. On the CBP2 traces the average falls from 86.311
to 8.962~MPKI.
